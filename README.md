# Análise do Uso de Inteligência Artificial por Faixa Etária

Este projeto analisa o uso de ferramentas de Inteligência Artificial generativa entre diferentes faixas etárias, utilizando dados oficiais do Eurostat referentes à União Europeia.

Desenvolvido em Python no Google Colab, o projeto utiliza as bibliotecas Pandas, NumPy e Plotly para coleta, tratamento e visualização dos dados. Também conta com o desenvolvimento de um dashboard interativo utilizando Streamlit.

O objetivo é identificar diferenças no uso da IA entre gerações e comparar suas principais finalidades, como educação, trabalho e uso pessoal.

**Tecnologias:** Python, Pandas, NumPy, Plotly, Streamlit e API do Eurostat.
